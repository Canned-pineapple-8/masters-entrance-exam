### 1. Типы команд SQL

Язык SQL (Structured Query Language) является декларативным языком: пользователь формулирует, какой результат требуется получить, а не последовательность шагов его получения. Совокупность команд SQL принято делить на несколько подъязыков (групп операторов) в зависимости от их назначения.

**Язык определения данных (DDL, Data Definition Language).** Команды этой группы предназначены для создания и изменения структуры объектов базы данных — таблиц, индексов, представлений, схем. К ним относятся операторы `CREATE` (создание объекта), `ALTER` (изменение структуры существующего объекта), `DROP` (удаление объекта) и `TRUNCATE` (полная очистка содержимого таблицы с сохранением её структуры).

**Язык манипулирования данными (DML, Data Manipulation Language).** Команды этой группы предназначены для работы непосредственно с содержимым (данными) объектов базы данных: `INSERT` (вставка новых строк), `UPDATE` (изменение значений существующих строк), `DELETE` (удаление строк).

**Язык запросов (DQL, Data Query Language).** Отдельно выделяемая (не во всех источниках) группа, состоящая по существу из единственного оператора `SELECT`, предназначенного для формирования запросов на выборку данных. В ряде классификаций оператор `SELECT` включают непосредственно в состав DML, не выделяя DQL как самостоятельную группу; общепринятого единого соглашения по этому вопросу нет, и данное деление на подъязыки в целом носит достаточно условный, а не строго формальный характер.

**Язык управления данными (DCL, Data Control Language).** Команды этой группы управляют правами доступа пользователей к объектам базы данных: `GRANT` (предоставление привилегии) и `REVOKE` (отзыв ранее предоставленной привилегии).

**Язык управления транзакциями (TCL, Transaction Control Language).** Команды этой группы обеспечивают управление транзакциями, рассмотренными в предыдущем вопросе: `COMMIT` (фиксация результатов транзакции), `ROLLBACK` (откат транзакции), `SAVEPOINT` (установка именованной точки сохранения внутри транзакции, до которой впоследствии можно выполнить частичный откат), а также `BEGIN TRANSACTION` (или `START TRANSACTION`), явно открывающий транзакцию в тех системах, где это требуется.

Реже в качестве самостоятельной группы выделяют также язык управления курсором (CCL, Cursor Control Language), объединяющий операторы `DECLARE CURSOR`, `OPEN`, `FETCH` и `CLOSE`, используемые при построчной обработке результата запроса в процедурном коде.

### 2. Типы данных SQL

Тип данных столбца определяет, какого рода значения допустимо в нём хранить, сколько памяти он занимает и какие операции над ним допустимы. Конкретный набор поддерживаемых типов данных и их точное название несколько варьируются между различными СУБД, однако можно выделить несколько общих категорий, предусмотренных стандартом SQL.

**Числовые типы.** Делятся на точные и приближённые. К точным относятся целочисленные типы `INT` (`INTEGER`), `SMALLINT`, `BIGINT`, различающиеся допустимым диапазоном хранимых значений и объёмом занимаемой памяти, а также тип `DECIMAL` (`NUMERIC`) с фиксированной точностью, задаваемой двумя параметрами `DECIMAL(precision, scale)`, где `precision` — общее количество значащих цифр, а `scale` — количество цифр после десятичной точки; этот тип применяется в первую очередь для финансовых расчётов, где недопустимы ошибки округления. К приближённым (числам с плавающей точкой) относятся типы `FLOAT`, `REAL`, `DOUBLE PRECISION`.

**Символьные (строковые) типы.** Тип `CHAR(n)` хранит строку фиксированной длины $n$ (дополняемую пробелами при необходимости), тип `VARCHAR(n)` хранит строку переменной длины, не превышающей $n$ символов, а тип `TEXT` предназначен для хранения строк большого объёма без строгого ограничения длины.

**Типы даты и времени.** Тип `DATE` хранит календарную дату, тип `TIME` — время суток, тип `TIMESTAMP` (в ряде СУБД — `DATETIME`) — дату и время совместно; в некоторых системах дополнительно поддерживаются варианты с учётом часового пояса.

**Логический тип.** Тип `BOOLEAN`, хранящий значения «истина» либо «ложь», поддерживается большинством современных СУБД, хотя формально не входит в число базовых типов исходного стандарта SQL и реализован не во всех системах единообразно.

**Бинарные типы.** Типы `BINARY` и `BLOB` (Binary Large Object) предназначены для хранения произвольных двоичных данных (изображений, файлов) непосредственно в базе данных.

### 3. Функции SQL

Функции SQL делятся на две большие категории по числу обрабатываемых строк: скалярные функции выполняют вычисление над одним значением (или несколькими значениями одной строки) и возвращают одно значение для каждой обрабатываемой строки, тогда как агрегатные функции выполняют вычисление над целой группой значений одного столбца, взятых из нескольких строк, и возвращают единственное итоговое значение для всей группы.

**Агрегатные функции.** Применяются, как правило, совместно с оператором `GROUP BY` (группировка строк) и `HAVING` (фильтрация по результату агрегирования). За исключением `COUNT(*)`, все агрегатные функции игнорируют значения `NULL` при вычислении результата.

- `COUNT(*)` — подсчитывает общее число строк в результирующем наборе; `COUNT(выражение)` — подсчитывает число строк, для которых значение выражения отлично от `NULL`.
- `SUM(выражение)` — вычисляет сумму значений числового выражения по всем строкам группы.
- `AVG(выражение)` — вычисляет среднее арифметическое значений числового выражения.
- `MIN(выражение)`, `MAX(выражение)` — определяют минимальное и максимальное значения выражения; аргументом может служить не только числовое, но и строковое (сравнение по алфавиту) или временнóе значение.

Пример: `SELECT category, COUNT(*), AVG(price) FROM products GROUP BY category` — для каждой категории товаров вычисляет число товаров и среднюю цену.

**Математические функции.** Скалярные функции, выполняющие вычисления над отдельными числовыми значениями.

- `ABS(x)` — модуль (абсолютное значение) числа.
- `ROUND(x, n)` — округление числа $x$ до $n$ знаков после запятой.
- `CEILING(x)` (`CEIL(x)`) — наименьшее целое число, не меньшее $x$ (округление вверх).
- `FLOOR(x)` — наибольшее целое число, не превышающее $x$ (округление вниз).
- `POWER(x, y)` — возведение $x$ в степень $y$.
- `SQRT(x)` — квадратный корень.
- `MOD(x, y)` — остаток от целочисленного деления $x$ на $y$.
- `SIGN(x)` — знак числа ($-1$, $0$ или $1$).
- `RAND()` — генерация псевдослучайного числа.

Помимо перечисленных, большинство СУБД поддерживают и стандартные тригонометрические и логарифмические функции (`SIN`, `COS`, `TAN`, `LOG`, `EXP` и другие), используемые существенно реже в типовых прикладных запросах.

**Функции даты и времени.** Скалярные функции, выполняющие вычисления над значениями типов `DATE`, `TIME`, `TIMESTAMP`.

- `NOW()` (либо `CURRENT_TIMESTAMP`) — текущие дата и время.
- `CURDATE()` (либо `CURRENT_DATE`) — текущая дата.
- `YEAR(d)`, `MONTH(d)`, `DAY(d)` — извлечение соответствующей составляющей из значения даты; равносильную, стандартизированную форму этой операции даёт конструкция `EXTRACT(YEAR FROM d)`.
- `DATEDIFF(d1, d2)` — разность между двумя датами, выраженная в заданных единицах (днях, месяцах и так далее, в зависимости от конкретной реализации в СУБД).
- `DATE_ADD(d, INTERVAL n unit)` (в некоторых СУБД — `DATEADD`) — прибавление к дате заданного интервала времени (например, `INTERVAL 7 DAY`).

Существенно, что точный набор функций и их сигнатуры (особенно для функций даты и времени) заметно различаются между конкретными СУБД (MySQL, PostgreSQL, Microsoft SQL Server, Oracle), поэтому при переносе SQL-кода между различными платформами эти различия необходимо учитывать отдельно.
