### 1. Общая постановка задач комбинаторики выбора

Пусть имеется множество из $n$ различных (различимых) объектов. Из него тем или иным способом выбирают (или переставляют) $m$ объектов ($m \leqslant n$, если выбор происходит без повторений, либо $m$ — произвольное натуральное число, если повторения разрешены). Получающиеся комбинации классифицируют по двум независимым признакам: важен ли порядок следования выбранных объектов, и допускается ли повторное использование одного и того же объекта. Сочетание этих двух признаков даёт шесть основных комбинаторных конфигураций, формулы для подсчёта числа которых рассматриваются ниже.
### 2. Перестановки без повторений

Перестановкой из $n$ различных объектов называется всякий способ расположить все эти $n$ объектов в определённом порядке (то есть выбираются все $n$ объектов, и имеет значение только порядок их следования). Число различных перестановок из $n$ объектов обозначается $P_n$ и равно

$$
P_n = n! = 1 \cdot 2 \cdot 3 \cdots n.
$$

Формула получается непосредственно из правила произведения: на первое место можно поставить любой из $n$ объектов, на второе место — любой из оставшихся $n-1$ объектов, и так далее, на последнее место — единственный оставшийся объект; перемножая число вариантов на каждом шаге, получаем $n \cdot (n-1) \cdots 1 = n!$.

**Пример.** Три книги на полке можно расставить $P_3 = 3! = 6$ различными способами.

### 3. Перестановки с повторениями

Пусть среди $n$ объектов имеется $k$ различных типов, причём объектов первого типа — $n_1$ штук, второго типа — $n_2$ штук, и так далее, $n_1 + n_2 + \dots + n_k = n$, при этом объекты одного типа неразличимы между собой. Число различных перестановок такого набора (число различных способов расположить все $n$ объектов в ряд с учётом неразличимости объектов одного типа) равно

$$
P(n_1, n_2, \dots, n_k) = \frac{n!}{n_1!\, n_2! \cdots n_k!}.
$$

Эта формула получается из числа перестановок $n!$ различимых объектов делением на число $n_1! \cdot n_2! \cdots n_k!$ — количество перестановок, отличающихся лишь порядком следования неразличимых объектов внутри каждой группы и потому дающих одну и ту же, фактически не различающуюся, перестановку.

**Пример.** Число различных «слов» (перестановок букв), которые можно составить из букв слова «МАМА» (буква М встречается дважды, буква А — дважды, всего $n=4$ буквы), равно

$$
P(2,2) = \frac{4!}{2!\,2!} = \frac{24}{4} = 6.
$$

### 4. Размещения без повторений

Размещением без повторений из $n$ различных объектов по $m$ ($m \leqslant n$) называется всякий упорядоченный набор из $m$ различных объектов, выбранных из данных $n$ (то есть выбирается лишь часть объектов, притом важен порядок их следования, и повторный выбор одного и того же объекта не допускается). Число размещений обозначается $A_n^m$ и равно

$$
A_n^{m} = n(n-1)(n-2)\cdots(n-m+1) = \frac{n!}{(n-m)!}.
$$

Формула вновь получается по правилу произведения: на первое место набора можно поставить любой из $n$ объектов, на второе — любой из оставшихся $n-1$, и так далее, вплоть до $m$-го места, для которого остаётся $n-m+1$ вариантов.

**Пример.** Число способов выбрать и расставить на пьедестале почёта (1-е, 2-е, 3-е места) призёров соревнования, в котором участвуют $10$ человек, равно

$$
A_{10}^{3} = 10 \cdot 9 \cdot 8 = 720.
$$

### 5. Размещения с повторениями

Размещением с повторениями из $n$ различных объектов по $m$ называется всякий упорядоченный набор длины $m$, каждый элемент которого независимо выбирается из данных $n$ объектов, причём повторное использование одного и того же объекта разрешено (в частности, $m$ здесь может быть как меньше, так и больше $n$). Число таких размещений обозначается $\overline{A}_n^{m}$ и равно

$$
\overline{A}_n^{m} = n^{m}.
$$

Формула следует из правила произведения: на каждую из $m$ позиций набора независимо от остальных можно поставить любой из $n$ объектов, что даёт $\underbrace{n \cdot n \cdots n}_{m} = n^m$.

**Пример.** Число различных четырёхзначных PIN-кодов, составленных из цифр $0,1,\dots,9$ (цифры могут повторяться), равно

$$
\overline{A}_{10}^{4} = 10^4 = 10\,000.
$$
### 6. Сочетания без повторений

Сочетанием без повторений из $n$ различных объектов по $m$ ($m \leqslant n$) называется всякий неупорядоченный набор (подмножество) из $m$ различных объектов, выбранных из данных $n$ — в отличие от размещения, здесь порядок выбранных объектов роли не играет, важен лишь их состав. Число сочетаний обозначается $C_n^m$ и равно

$$
C_n^{m} = \binom{n}{m} = \frac{n!}{m!\,(n-m)!}.
$$

Формула получается из формулы для размещений делением на число $m!$ — количество способов упорядочить один и тот же набор из $m$ выбранных объектов, которые в размещении считались различными комбинациями, а в сочетании отождествляются в одну:

$$
C_n^{m} = \frac{A_n^{m}}{m!} = \frac{n!}{(n-m)!\,m!}.
$$

**Пример.** Число способов выбрать команду из $3$ человек (без разделения ролей) из группы в $10$ человек равно

$$
C_{10}^{3} = \frac{10!}{3!\,7!} = \frac{10 \cdot 9 \cdot 8}{3 \cdot 2 \cdot 1} = 120.
$$
### 7. Сочетания с повторениями

Сочетанием с повторениями из $n$ различных типов объектов по $m$ называется всякий неупорядоченный набор из $m$ объектов, каждый из которых принадлежит одному из $n$ типов, причём объекты одного типа могут повторяться в наборе произвольное число раз (важен лишь состав набора — сколько объектов какого типа в него вошло, но не порядок). Число таких сочетаний обозначается $\overline{C}_n^{m}$ и равно

$$
\overline{C}_n^{m} = C_{n+m-1}^{m} = \frac{(n+m-1)!}{m!\,(n-1)!}.
$$

Эта формула обосновывается методом «звёзд и перегородок»: набор из $m$ объектов $n$ типов, в котором объектов первого типа — $x_1$, второго — $x_2$ и так далее (причём $x_1 + \dots + x_n = m$, $x_i \geqslant 0$), однозначно кодируется последовательностью из $m$ звёздочек (единиц выбранного объекта) и $n-1$ перегородок, разделяющих группы разных типов; число таких последовательностей длины $m + n - 1$ равно числу способов выбрать позиции для $n-1$ перегородок среди всех $m+n-1$ позиций, то есть $C_{n+m-1}^{n-1} = C_{n+m-1}^{m}$.

**Пример.** Число способов выбрать $4$ пирожных из кондитерской, в которой представлено $3$ вида пирожных, если пирожные одного вида неразличимы, а вид можно выбирать многократно, равно

$$
\overline{C}_3^{4} = C_{3+4-1}^{4} = C_6^4 = \frac{6!}{4!\,2!} = 15.
$$

### 8. Сводная таблица

| | Порядок важен | Порядок не важен |
|---|---|---|
| **Без повторений** | Размещения: $A_n^m = \dfrac{n!}{(n-m)!}$ | Сочетания: $C_n^m = \dfrac{n!}{m!(n-m)!}$ |
| **С повторениями** | Размещения с повторениями: $\overline{A}_n^m = n^m$ | Сочетания с повторениями: $\overline{C}_n^m = C_{n+m-1}^m$ |

Перестановки представляют собой частный случай размещений при $m=n$ (перестановки без повторений, $A_n^n = n!= P_n$) либо особый случай подсчёта числа расстановок объектов с повторяющимися типами (перестановки с повторениями, отдельная формула из раздела 3).
