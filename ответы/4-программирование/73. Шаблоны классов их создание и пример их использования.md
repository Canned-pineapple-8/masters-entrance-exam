### 1. Понятие шаблона класса

Шаблоном класса называется средство языка C++, позволяющее описать обобщённый, не привязанный к конкретному типу данных класс, в котором один или несколько используемых типов (либо некоторые значения) выступают в роли параметров, подставляемых лишь впоследствии, при фактическом использовании этого класса в программе. Шаблоны классов служат основным техническим средством реализации параметрического (называемого также статическим) полиморфизма, рассмотренного ранее в вопросе о полиморфизме, и позволяют существенно сократить дублирование кода, избавляя от необходимости писать отдельную, содержательно идентичную реализацию класса (например, контейнера) для каждого конкретного типа хранимых им данных.

### 2. Синтаксис объявления шаблона класса

Определение шаблона класса начинается с ключевого слова `template`, за которым в угловых скобках указывается список параметров шаблона, а далее следует обычное объявление класса (или структуры), в теле которого эти параметры могут использоваться наравне с обычными, конкретными типами:

```c++
template <typename T>
class Stack {
public:
    void Push(const T& value) {
        data.push_back(value);
    }
    void Pop() {
        data.pop_back();
    }
    const T& Top() const {
        return data.back();
    }
    bool IsEmpty() const {
        return data.empty();
    }
private:
    std::vector<T> data;
};
```

Параметром шаблона может служить как тип (объявляемый ключевым словом `typename` либо, равносильным образом, `class`), так и значение одного из ограниченного набора допустимых для этой цели типов — целое число, перечисление, указатель или ссылка на объект с внешним связыванием (так называемый нетиповой параметр шаблона); при необходимости шаблон может принимать сразу несколько параметров, перечисляемых через запятую:

```c++
template <typename T, int Size>
class FixedArray {
public:
    T& operator[](int index) { return data[index]; }
private:
    T data[Size];
};
```

### 3. Инстанцирование шаблона класса

Инстанцированием шаблона называется процесс порождения из общего, параметризованного описания шаблона конкретного, полноценного класса путём подстановки конкретных значений параметров шаблона. Компилятор создаёт отдельный, самостоятельный класс для каждого уникального набора аргументов шаблона, фактически встретившегося в программе:

```c++
Stack<int> intStack;
Stack<std::string> stringStack;

intStack.Push(42);
stringStack.Push("hello");
```

Здесь `Stack<int>` и `Stack<std::string>` представляют собой два различных, независимо сгенерированных компилятором класса, порождённых из единого шаблона `Stack` подстановкой соответственно типов `int` и `std::string` вместо параметра `T`.

### 4. Определение методов шаблона класса вне его тела

Если методы шаблона класса определяются не непосредственно внутри его тела, а отдельно (например, ради разделения объявления и реализации на разные файлы), синтаксис такого определения должен явно повторять список параметров шаблона как перед самим определением метода, так и в квалификации имени класса:

```c++
template <typename T>
class Container {
public:
    void Add(const T& value);
private:
    std::vector<T> items;
};

template <typename T>
void Container<T>::Add(const T& value) {
    items.push_back(value);
}
```

### 5. Специализация шаблона класса

Специализация позволяет предоставить для определённого конкретного типа (или ограниченного семейства типов) собственную, отличную от общей, реализацию шаблона класса, — что бывает полезно, когда стандартная, обобщённая реализация неэффективна или неприменима для этого конкретного случая.

**Полная специализация** задаёт целиком самостоятельную реализацию шаблона для одного строго определённого набора конкретных аргументов; при этом специализированная версия вовсе не обязана повторять состав членов исходного, общего шаблона — она может произвольно изменять, добавлять или опускать любые из них:

```c++
template <>
class Stack<bool> {
    // отдельная, более компактная (побитовая) реализация специально для типа bool
};
```

**Частичная специализация**, применимая исключительно к шаблонам классов (но не к шаблонам функций), задаёт специализированную реализацию не для одного конкретного типа, а для целого семейства типов, подчиняющихся определённому шаблонному соответствию (например, для всех указательных типов):

```c++
template <typename T>
class Stack<T*> {
    // отдельная реализация, общая для стека, хранящего указатели произвольного типа
};
```

При использовании шаблона класса с конкретным аргументом компилятор автоматически выбирает наиболее подходящую из доступных реализаций — специализированную, если для данного (или, в случае частичной специализации, соответствующего шаблону) аргумента таковая определена, либо, в противном случае, исходную, общую версию шаблона.

### 6. Пример использования

```c++
template <typename T>
class Stack {
public:
    void Push(const T& value) { data.push_back(value); }
    void Pop() { data.pop_back(); }
    const T& Top() const { return data.back(); }
    bool IsEmpty() const { return data.empty(); }
private:
    std::vector<T> data;
};

int main() {
    Stack<int> numbers;
    numbers.Push(10);
    numbers.Push(20);
    std::cout << numbers.Top() << "\n";   // выведет 20
    numbers.Pop();
    std::cout << numbers.Top() << "\n";   // выведет 10

    Stack<std::string> words;
    words.Push("Hello");
    words.Push("World");
    std::cout << words.Top() << "\n";     // выведет World
}
```

Приведённый пример демонстрирует ключевое практическое достоинство шаблонов классов: единая реализация `Stack`, написанная и отлаженная лишь однажды, оказывается пригодна для работы с данными произвольного типа — как встроенного (`int`), так и пользовательского (`std::string` и любого другого класса) — без необходимости переписывать логику класса заново для каждого конкретного типа хранимых данных.
