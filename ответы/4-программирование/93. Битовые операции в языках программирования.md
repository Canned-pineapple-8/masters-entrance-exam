### 1. Понятие битовых операций

Битовыми (побитовыми) операциями называются операции, действующие непосредственно на отдельные разряды (биты) двоичного представления целочисленного операнда. В отличие от логических операций, рассмотренных ранее (в вопросах о булевой алгебре и логических операциях) и оперирующих единственным логическим значением («истина» или «ложь»), битовая операция применяет ту же самую логику одновременно и независимо к каждому разряду двоичного представления числа, обрабатывая, таким образом, сразу всю совокупность битов операнда за одно действие. Битовые операции определены исключительно для целочисленных типов данных и неприменимы напрямую к вещественным числам.

### 2. Основные битовые операции

**Побитовое И (`&`).** Результирующий бит равен единице тогда и только тогда, когда соответствующие биты обоих операндов равны единице.

```c++
int a = 0b1100;   // 12
int b = 0b1010;   // 10
int c = a & b;    // 0b1000 = 8
```

**Побитовое ИЛИ (`|`).** Результирующий бит равен единице, если хотя бы один из соответствующих битов операндов равен единице.

```c++
int c = a | b;    // 0b1110 = 14
```

**Побитовое исключающее ИЛИ (`^`, XOR).** Результирующий бит равен единице тогда и только тогда, когда соответствующие биты операндов различны.

```c++
int c = a ^ b;    // 0b0110 = 6
```

Операция XOR обладает рядом полезных на практике алгебраических свойств: $x \oplus x = 0$, $x \oplus 0 = x$, и, что особенно существенно, она является собственной обратной операцией самой себе, то есть $(x \oplus y) \oplus y = x$, — на этом свойстве, в частности, основан известный приём обмена значений двух переменных без привлечения дополнительной, третьей переменной (хотя на практике этот приём чаще представляет теоретический интерес, чем реальную практическую ценность, уступая по ясности и безопасности обычному обмену через временную переменную или стандартную функцию `std::swap`).

**Побитовое НЕ (`~`).** Унарная операция, инвертирующая каждый без исключения бит операнда (заменяющая каждый нулевой бит на единичный и наоборот).

```c++
int c = ~a;   // инвертирует все биты числа a
```

**Сдвиг влево (`<<`).** Сдвигает все биты операнда на заданное число позиций влево, заполняя освобождающиеся младшие разряды нулями; для значений, не приводящих к переполнению разрядной сетки, сдвиг влево на $k$ позиций равносилен умножению на $2^k$.

```c++
int c = a << 2;   // равносильно умножению a на 4 (при отсутствии переполнения)
```

**Сдвиг вправо (`>>`).** Сдвигает все биты операнда на заданное число позиций вправо; конкретное поведение при этом существенно зависит от того, является ли тип операнда знаковым или беззнаковым. Для беззнаковых типов применяется логический сдвиг: освобождающиеся старшие разряды заполняются нулями. Для знаковых типов при сдвиге отрицательного значения применяется арифметический сдвиг: освобождающиеся старшие разряды заполняются не нулями, а значением исходного знакового бита (так называемое расширение знака), что сохраняет знак числа неизменным и соответствует делению значения на $2^k$ с округлением в сторону минус бесконечности (что важно отличать от обычного целочисленного деления, округляющего результат к нулю, — для отрицательных значений эти два результата, вообще говоря, различаются).

```c++
int x = -16;      // ...11110000 в дополнительном коде
int y = x >> 2;   // ...11111100 = -4 (знаковый бит скопирован в освободившиеся разряды)
```

### 3. Типичные применения битовых операций

Наиболее распространённая область практического применения битовых операций — работа с битовыми масками, позволяющими компактно закодировать набор независимых логических признаков (флагов) в виде отдельных разрядов единственной целочисленной переменной, что экономит память и позволяет проверять или изменять сразу несколько признаков за одну машинную операцию.

**Установка бита в позиции $n$** (перевод его в состояние 1, независимо от исходного значения):
```c++
x |= (1 << n);
```

**Сброс бита в позиции $n$** (перевод его в состояние 0, независимо от исходного значения):
```c++
x &= ~(1 << n);
```

**Инвертирование (переключение) бита в позиции $n$** (замена его текущего значения на противоположное):
```c++
x ^= (1 << n);
```

**Проверка состояния бита в позиции $n$:**
```c++
bool isSet = (x >> n) & 1;
```

Помимо работы с отдельными флагами, битовые операции применяются для быстрого умножения и деления на степени двойки посредством сдвигов (что на некоторых аппаратных платформах существенно быстрее универсальных операций умножения и деления), а также в разнообразных низкоуровневых задачах — сжатии данных, криптографии, кодировании изображений и сигналов, реализации хеш-функций и во многих иных областях, где важны компактность представления данных и высокая скорость их обработки.

### 4. Связь с алгеброй логики

Существенно отметить, что все рассмотренные битовые операции (за исключением сдвигов, не имеющих прямого аналога в булевой алгебре) в точности реализуют операции алгебры логики, рассмотренные ранее в разделе о булевой алгебре и логических операциях, — с той лишь разницей, что применяются они не к единственному логическому значению, а параллельно, независимо, к каждому из разрядов двоичного представления целочисленного операнда. В частности, для битовых операций справедливы все рассмотренные ранее алгебраические тождества булевой алгебры, включая законы де Моргана: побитовое отрицание результата операции `|` эквивалентно результату применения операции `&` к побитовым отрицаниям исходных операндов, и наоборот.
